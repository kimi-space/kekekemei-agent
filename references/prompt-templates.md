# 视频 Prompt 模板

## 通用规则

- **首句风格锚点一字不差**：`二次元细腻插画风，Q版萌系猫耳角色，柔和光照，温馨日常氛围，高清渲染`
- **人设参考**：每段视频都传入人设图作为参考图；prompt 里复述外观锚点。**参考人设图只锁定五官/发色/猫耳，不锁服装**——必须另写一句："人设图仅参考脸型发色猫耳，服装按本段文字描述，不要换回参考图上的衣服"。
- **比例锁定（防身高漂移）**：每段都必须额外传入 `assets/可可可妹_比例参考.jpg`，并写"人物头身比与比例参考图完全一致：约2.5头身、头大身短腿短；**可可和可妹身高一样高，比例照图里可妹的体型**，不要随便把某个人画高或画矮"。用户没说要变身高，就一律不许改。**特别注意：即使角色在镜头里只是路过、特写、局部入镜，身体也必须是Q版短手短腿，绝不能因镜头拉近画成正常成年人比例**。
- **服装锁定（防换装漂移）**：本场服装一旦在脚本里定好，**每一段 prompt 都要逐字复述一遍完整服装描述**，并写"两人始终穿着本场服装，中途不换衣服"。
- **音色锁定（防声音变脸）**：每个说话角色后面必须复述声线（见 characters.md 音色表），同一角色在所有段落里声线一字不差：可可=清亮少年音、语速偏快、笑起来开朗；可妹=清甜少女音、傲娇时尾音上扬。
- **台词**：用 `{台词原文}` 包裹，保证口型同步。**字幕默认不加**——用户没明确要求字幕时，prompt 里不写任何字幕相关内容；用户明确要求字幕时，才写"画面底部出现与台词一致的中文字幕"。
- **时长**：每段 10 秒；比例 9:16。
- 手部动作按 `storyboard.md` 标准写法复述手指姿势。

## 单段视频 prompt 模板（I2V）

```text
二次元细腻插画风，Q版萌系猫耳角色，柔和光照，温馨日常氛围，高清渲染。
人设参考图仅用于锁定可可和可妹的脸型、发色、猫耳和五官，服装按本段描述，不要换回参考图上的衣服。
可可：银白短发呆毛+白色猫耳猫尾、蓝色大圆眼；本场穿着___（完整服装逐字复述）。
可妹：银白长卷发+白色猫耳猫尾、蓝色大眼脸颊泛红、黑色猫形发夹+蓝色发卡；本场穿着___。
场景：___；光线：___。
本镜头：可可（动作/表情）___；可妹（动作/表情）___。
手部动作：___。
可可用清亮少年音、语速偏快地说{台词原文}；可妹用清甜少女音、傲娇尾音上扬地说{台词原文}，口型与台词同步。
（默认无字幕；用户明确要求字幕时才追加：画面底部出现与台词一致的字幕。）人物比例稳定，动作流畅，两人服装全程不变、不换回人设图服装，无手指数量错误，10秒，9:16。
```

## 对话段示例（烧烤 vs 火锅）

```text
……客厅场景，白天自然光。
可可叉腰大喊：{吃烧烤！}
可妹抱臂傲娇回喊：{吃火锅！}
可可叉腰再喊：{吃烧烤！}
可妹抱臂再回：{吃火锅！}
可可双手握拳举过头顶，兴奋地说{公平决斗！石头剪刀布！}
两人同时出手：可可右手五指握拳；可妹右手伸出食指和中指两根手指、其余握拳。
可可仰头大笑{哈哈哈，我赢了！}
```

## 段间衔接写法（防亮度跳变）

- **第 2 段起必须把上一段最后一帧截图作为参考图列表的第一张**（最强衔接锚点），prompt 第一句就写：`本段第一帧就是参考图1的画面，从这个画面继续往下演`，让模型真的把尾帧当首帧，而不是当风格参考。
- **光线四要素逐字复制**：脚本里定好的光线（时段/主光方向/色温/整体亮度，如"暖黄壁灯侧光、约3000K、中等亮度、阴影柔和"）必须在每一段 prompt 里**一字不差地重复**，不许第二段自己换个说法。
- prompt 开头追加：`延续上一段：角色仍在原位置，保持上一段结尾的姿势和表情，动作自然衔接；与上一段保持完全一致的曝光、亮度、色温、主光方向和对比度，不得突然变亮、变暗、偏黄或偏蓝，两段拼在一起肉眼看不出亮度差别；两人继续穿着本场服装（___逐字复述___），声线与上一段完全一致。`
- 机位、场景、服装、声线与上一段保持一致。

## 负向约束（每条都带）

手指数量正确；不出现多余手指或缺手指；**每个角色只有一条尾巴、两只耳朵，不多尾巴不多耳朵**；**小咪和小旺都是正常四条腿，不多腿不少腿**；角色不变形、不换脸；猫耳猫尾位置稳定；宠物数量正确（小咪一只、小旺一只）；不跳场景；相邻段亮度色温完全一致、拼接处无明暗跳变；默认画面无字幕（用户要求字幕时才与台词一致）。
