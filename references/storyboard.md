# 脚本优化规则与分段模板

## 用途

用户用自然语言讲一个**大概剧情（可以粗糙、缺表情动作）**。本文件规定如何把它优化成可直接生成的分段台词本。

## 优化原则

1. **逻辑修顺**：用户剧情里不通顺、动机矛盾、因果断裂的地方，按"日常小剧场"逻辑补顺，不改用户的核心笑点/反转。
2. **对话改编号台词表**：禁止"可可和可妹来回说三次"这种自然语言——必须写成一句一句、谁说是谁说、一字不差。
3. **补全细节**：用户没写表情/动作/语气时，按 `characters.md` 人设自动补（可可外放、可妹傲娇），不反问用户。
4. **每段 10 秒**：按剧情长度拆成 N 段，每段约 3-5 句短台词；塞不下就拆段，不硬塞。
5. **前 3 秒钩子**：每段开头 3 秒内必须出现冲突、笑点、悬念或角色亮相，不许铺垫。
6. **结尾**：每段结尾给反转、笑点落地或钩子；最后一段收在温馨/好笑/悬念。

## 场景规则

- **相邻段必须同一场景**：第 1 段在客厅，第 2 段不能无故变大街。
- **转场**：只在用户明确写「转场：从 X 到 Y」时才换场景；换场前后两段分别写清新场景。
- **光线要写具体**：每个场景的【光线】必须写清四要素：时段（清晨/白天/傍晚/夜晚）、主光方向（左窗自然光/顶光/暖台灯）、色温（冷白/暖黄）、整体亮度（偏亮/中等/偏暗）。允许随剧情时间流逝变化（白天吵架 → 夜晚暖光吃火锅），但一旦定下，同场景多段之间逐字不变。

## 段间衔接（强制）

- **段尾衔接画面 = 下一段开头延续**：上一段最后一秒角色在做什么/站在哪/什么表情，下一段第一秒必须接上同一动作、同一机位、同一光线。
- **亮度与色温一致（防拼接跳变，强制）**：相邻段的整体亮度、对比度、色温必须完全一致。第 2 段起：① 用上一段最后一帧截图作为本段首帧参考图；② prompt 里必须带"与上一段相同的曝光、亮度、色温、主光方向，不得突然变亮/变暗/偏黄/偏蓝"。
- 台词也接：上一段最后一句的语气/话题 = 下一段第一句回应的话题。

## 分段台词本模板（输出给用户确认的格式）

```
【故事一句话】___
【场景】___（本场在哪里；如有转场在此写明）
【光线】___（写清四要素：时段+主光方向+色温+整体亮度，如：清晨、左窗自然光、暖白、整体偏亮）
【本场服装】可可：___；可妹：___（默认沿用锚点服装，换装才写）

▶ 第 1 段（10s）
镜头：___（景别/机位，如：两人中景对峙）
台词：
  ① 可可（表情/动作）：{台词原文}
  ② 可妹（表情/动作）：{台词原文}
  ③ ……
手部/道具动作：___（如：可可右手握拳；可妹伸出食指+中指两根手指）
情绪氛围：___
本段结尾画面：___（= 第 2 段开头要接上的）

▶ 第 2 段（10s）
……（同上字段）

【反转/结尾】___
```

## 手部动作写法（防画错）

| 动作 | 标准写法 |
|---|---|
| 石头 | 五指握拳 |
| 剪刀 | 伸出食指和中指两根手指，其余三根握拳 |
| 布 | 五指张开 |
| 递勺子 | 右手握勺柄、手指自然弯曲 |
| 抱臂 | 双臂交叉抱在胸前 |
| 指人 | 右手伸出食指指向对方 |

## 输出前自检（强制，输出台词本之前必须逐项过一遍）

把台词本交给用户之前，**先按下面清单在心里过一遍**，发现问题先自己改好再输出，不要把有逻辑/动作硬伤的本子抛给用户：

1. **道具位置对不对**：谁手里拿着什么、丢在哪里、后来谁去捡/盖/拿——前后一致（例：可可丢下的是打火机，那盆底下就必须是打火机，不能写成"空空的"）。
2. **动作因果成立**：每个动作都有起因和结果；先点炮再跑、先盖盆再抬盆，顺序不能乱。
3. **谁在哪**：每一段谁在画面里、谁出画、谁画外说话，写清楚，不张冠李戴。
4. **笑点/反转落地**：用户写的包袱在哪个镜头、靠什么视觉或台词接住，写明确。
5. **10 秒塞得下**：每段台词和动作密度合理，不硬塞；塞不下就拆段。
6. **段间衔接**：上一段结尾画面 = 下一段开头，光线四要素逐字一致。
7. **声音**：每句台词标了是谁说、什么声线；拟声词不冒充台词。

## 输出规则

- 自检通过后再输出完整分段台词本，附上"我做了哪些优化"的简短说明（改了哪句、补了什么动作）。
- 等用户确认后才进入视频生成；用户要改哪里改哪里。
