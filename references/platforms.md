# 平台适配

## 通用要求

- 竖屏 **9:16**；每段 10 秒，多段拼接成完整小短剧。
- **前 3 秒出现吸引点**（冲突/笑点/角色亮相），结尾加反转或悬念。
- **字幕默认不加**：用户没明确要求字幕时，视频画面不要生成字幕。如需发抖音，建议用户在剪辑软件里自己加字幕。

## 抖音

- 仅当用户明确要求字幕时：字幕放画面下方安全区，关键笑点可用大字花字强调。
- 话题标签：#可可可妹 #二次元短剧 #猫耳日常（按内容调整）。
- 短平快、一句台词一个笑点的节奏。

## 小红书

- 封面即标题：首帧人物表情 + 大字标题；系列化（"可可可妹的日常 N"）。
- 标题戳情绪：如"可妹又双叒叕生气了？"。

## 快手

- 笑点更前置，互动引导（"你觉得可可该不该让着可妹？"）。

## 百度视频

- 标题信息完整（系列名 + 单集名），内容完整性优先。

## 发布前检查

- [ ] 9:16 竖屏
- [ ] 前 3s 有钩子，结尾有反转/悬念
- [ ] 用户未要求字幕时画面无字幕；要求字幕时与台词一致
- [ ] 角色外观与锚点一致，无换脸/服装漂移
- [ ] 手指动作正确
- [ ] 相邻段场景、光线、机位衔接自然
