# 角色锚点库（可可 / 可妹 / 小咪 / 小旺）

## 使用方式

- 本文件是**唯一的角色权威来源**，所有视频 prompt 的外观描述必须与这里一致。
- 人设参考图：
  - **角色设定图：`assets/可可可妹_角色设定.jpg`**（★最高优先级：白底全身立绘，两人并排正面站立，锁脸型、发色、猫耳、身高差、Q版比例、帆布鞋；每次生成必传）。
  - **标准帧：`assets/可可可妹_标准帧.jpg`**（玉米地场景同框帧，辅助锁场景氛围和身高差）。
  - **比例参考：`assets/可可可妹_比例参考.jpg`**（沙发坐姿双人图，辅助锁定 Q 版头身比例）。
  - **同框参考：`assets/可可可妹_客厅参考.jpg`、`可可可妹_站姿参考.jpg`**（两人同框视频帧，仅在需要同框互动姿势时参考）。
  - **小咪（黑猫）：`assets/小咪_人设图.png`**（官方设定图，含表情展示、正/侧/背/顶三视图、项圈/爪印/尾巴细节）。
  - **小旺（小狗）：`assets/小旺_人设图.png`**（官方设定图，含表情展示、正/侧/背/顶三视图、三角巾/骨头牌/脚掌细节）。
- 生成视频时把角色设定图 + 标准帧作为必传参考图（I2V），并复述下列文字锚点。
- **永远不变**：银白发色、猫耳猫尾。**黑猫发夹+蓝黑条纹发卡是可妹专属，可可头上没有。**
- **可以变**：服装随场景更换；但同一批镜头里两人服装必须一致。
- 人设图上的背景文字只做装饰，**不要写进剧情、台词或画面**。

## 风格锚点（每个 prompt 首句一字不差）

```text
二次元细腻插画风，Q版萌系猫耳角色，柔和光照，温馨日常氛围，高清渲染
```

## 外观锚点复述清单（每个镜头必写）

银白发色与发型、猫耳（内侧粉绒）与猫尾、脸型、眼型与瞳色、**头身比例（约2.5头身、头大身短腿短、和比例参考图一致）**、本场服装、标志性配件、表情气质。

## 同框一致性要求

- 两人同框时**不能长得一样**：可可短发外放、可妹长卷发；发型体积要拉开。
- **年龄感/体型跨段一致**：每段都要复述"Q版圆脸大头、2.5-3头身、同一年龄感"，转场新场景也不例外，禁止一段像小学生一段像高中生。
- **身高差固定**：可可比可妹略高一点（约1/4头差），比例全部照 `assets/可可可妹_标准帧.jpg`；这个身高差是人设，**任何一段、任何场景都不许改**，用户没提身高就保持原样。
- 服装主色可以各自不同，但同一场景内两人都不换衣服。
- **服装图案统一**：所有衣服上的印花/图案都要和猫耳主题一致（猫爪印、小猫脸等），画风跟随人设图，不要凭空出现无关图案或文字。
- 手部：按 SKILL.md 动作规则写清手指姿势，防止"剪刀只伸一根食指"。

## 音色（标准声线，全片锁定）

以下声线以"吓晕可可"视频提取的真实人声为准，**是所有视频的唯一标准**：每个角色只要出声（说话、惊叫、打呼、叹气），prompt 里都必须逐字复述对应声线，**不许换声线、不许换年龄感**。

**声音参考文件（已从成片中分离人声）：**
- 可可：`assets/可可_声音参考.wav`（含"在一起久了没感觉""心跳加速""哇——！"三段）
- 可妹：`assets/可妹_声音参考.wav`（含"什么感觉？""那我这就去换给你看"两段）

| 角色 | 标准声线（逐字复述） |
|---|---|
| 可可 | 清亮少年音，语速偏快，带点调皮，笑起来很开朗；惊叫时声音拔高发颤 |
| 可妹 | 清甜少女音，语气娇俏，傲娇/生气时尾音上扬，撒娇时变软；坏笑时拖长音 |
